# 运行程序

## 视频播放与测量（默认，不连接摄像头）

把 `拍摄视频.mp4` 放到项目目录。默认启动桌面测量：

```bash
python3 main.py
```

原图、开/闭运算和四路灰度波形随视频播放；支持暂停、继续、从头播放和 F11 全屏。预览循环，设备处理慢时播放会变慢，不跳帧。

1. 检查干涉中心和四点位置；当前视频默认中心为 `(720, 290)`，可单击原图调整。
2. 点击“开始记录”：从视频第一帧重新采集，到最后一帧自动暂停并分析，不跨循环累计。
3. 点击“计算并保存”：计算波长，保存原始四路灰度、视频时间戳和结果。

界面读数单位为 mm。当前配置按用户确认值预填 `528.2525` 和约 `528.2692` mm（来自 `52.82525`、约 `52.82692` cm），并保留“参考波长反推后经用户复查”的来源，不用于独立精度验证。换视频时必须更换中心与起止读数。提前停止只能分析部分视频，结束读数须对应停止时刻，不能沿用完整视频终点。

## 可视化调节二值化阈值

在右侧“显示处理”点击“可视化调节二值化阈值”。窗口同时显示原始灰度、二值图、开运算和闭运算。

当前视频默认显示阈值为 **65**（用户对比后选定），仍可调整或切回自动；该值不参与测量计数。

- 拖动 0–255 滑块，自动切换为手动阈值；降低阈值会增加白色区域，提高阈值会减少白色区域。
- 勾选“冻结对比帧”，在同一帧上比较阈值；选择条纹可分辨、相邻条纹不粘连的值，再取消冻结检查整段视频。
- 点击“应用到主界面/网页”，两边同步使用当前阈值。只影响显示，不改变计数和原始灰度；冻结画面也不停止测量采样。
- 本次选择仅当前运行有效；长期使用可把 `config.json` 的 `preview.threshold` 改为选定数值，`null` 表示自动阈值。

## 网页播放

只用网页展示（可在 SSH 中启动）：

```bash
python3 main.py --web --headless --host 0.0.0.0
```

电脑浏览器打开 `http://香橙派IP:8080`。需要测量、调阈值并同时图传时使用 `python3 main.py --web --host 0.0.0.0`，不要加 `--headless`；该界面须在香橙派桌面或远程桌面会话运行。网页只读，测量、暂停和阈值在桌面操作；网页约 8 帧/秒，不修改原始测量数据。

视频文件不上传 GitHub，需另行复制到香橙派。更新代码用 `git pull --ff-only`。其他视频可用 `--play-video "/完整路径/视频.mp4"`；默认文件和中心在 `config.json` 的 `video` 中配置，相对视频路径以配置文件所在目录为准。按 Ctrl+C 停止网页服务；跨网络访问仍用文末 VPN/SSH 隧道。

## 手机视频离线分析

把 MP4 放在项目目录，运行：

```bash
python3 main.py --video "拍摄视频.mp4"
```

每帧都参与四点灰度采样，时间使用视频自带时间戳（不可用时采用帧号/帧率）。结果在新的 `data/video_.../` 文件夹：`raw.csv` 为逐帧原始四路灰度，`result.json` 为各路计数与一致性结果，`comparison.mp4` 为原图与开/闭运算对比。对比视频约 8 帧/秒，减帧仅用于显示，不影响采样。

默认四点中心为画面中心，不自动识别干涉中心。可用 `--roi-center X Y` 指定原视频像素坐标；用 `--video-start 20 --video-end 40` 分析指定时间段（秒），用 `--no-preview-export` 跳过对比视频导出。离线分析无需摄像头或桌面窗口，不与 `--web` 混用。视频文件需另行复制到香橙派，GitHub 只更新代码。

结果同时记录 632.8 nm 参考波长及由有效合并计数推算的位移 `inferred_displacement_mm`，公式为 N×632.8/2000000 mm。这是参考波长下的推算位移，不是千分尺读数；反代得到 632.8 nm 仅是公式校核。四点不能合并时保留各路原始结果，不改动计数凑出合并值。

在香橙派 Ubuntu 桌面或远程桌面的终端中，打开本项目文件夹。

首次安装依赖：

```bash
sudo apt update
sudo apt install python3-opencv python3-tk python3-pil.imagetk python3-numpy
```

先运行演示模式（不需要摄像头）：

```bash
python3 main.py --demo
```

仅需切回 USB 摄像头时，显式运行：

```bash
python3 main.py --camera 0
```

摄像头打不开时，可尝试：

```bash
python3 main.py --camera 1
```

测量步骤：

1. 固定摄像头和装置，保持外部环境稳定。单击画面选择干涉条纹中心，四个圆形 ROI 分布在上、右、下、左。
   在右侧“距中心 / px”调整间距，点击“应用”；记录中不能移动 ROI。
2. 测量前保持 M2 静止 30–60 秒，观察四路波形是否出现明显漂移或周期性变化；异常时先排查曝光、装置和光源，再进行测量。输入千分尺起始读数（mm），点击“开始记录”。
3. 单向、缓慢移动反射镜 M2。
4. 点击“停止并分析”，输入终止读数（mm）。
5. 查看各点周期数和有效点数量，点击“计算并保存”。结果保存在 `data` 文件夹；`_raw.csv` 保存原始四路灰度。

按 **F11** 或点击“全屏 F11”进入全屏，按 **Esc** 退出。图像会按比例缩放；右侧可用滚动条或鼠标滚轮查看参数，结果位于顶部。

上方是原始测量画面，单击这里选择 ROI；下方并排显示开运算和闭运算，最下方是原始四路灰度波形。下方处理不参与周期计数或波长计算。

“显示处理”默认使用 3×3 中值降噪、自动二值化阈值和 3 像素椭圆核。两幅图从同一二值图分别处理：开运算先腐蚀再膨胀，闭运算先膨胀再腐蚀。核大小可选 1/3/5/7（1 不改变二值图）；关闭自动阈值后，手动填写 0–255。先用 3，若细环消失或相邻环粘连就减小核。显示更连续不代表测量精度更高，自动阈值变化也可能造成视觉跳变。显示处理约每秒刷新 8 次，与采集线程分离。

四点分别分析周期数，至少三个有效点一致才合并；不直接平均灰度，以免不同相位相互抵消。用途是发现和剔除局部遮挡、低对比度等异常，不代表精度自动提高四倍。当前按外部环境稳定、条纹缓慢变化使用；这不是已验证的无误差条件，仍需检查曝光、采样和千分尺位移误差。尚无完整误差标定，界面不报告合成不确定度。

注意：普通 SSH 不直接显示程序窗口；摄像头应关闭自动曝光和自动增益，避免过曝；运动太快会漏计。千分尺分辨率未知时留空。

## 网页图传

电脑与香橙派连接同一路由器或热点。在香橙派项目目录运行（可通过 SSH）：

```bash
python3 main.py --web --headless --host 0.0.0.0
```

运行 `hostname -I` 查看香橙派的局域网 IP。在电脑浏览器输入 `http://香橙派IP:8080`，将“香橙派IP”替换为实际地址，不要输入 `0.0.0.0`。按 Ctrl+C 停止。

- 同时使用桌面测量界面：`python3 main.py --web --host 0.0.0.0`（在桌面会话运行）。
- 无摄像头测试：`python3 main.py --demo --web --headless --host 0.0.0.0`。
- 摄像头编号可加 `--camera 1`，端口可加 `--port 8081`，浏览器地址同步修改。
- 网页原图与开/闭运算来自同一帧，只读、约 8 帧/秒、尺寸限制为 640×480 内，JPEG 压缩；不是原始实验数据。显示参数与桌面同步，纯网页启动时使用配置中的值。
- `--headless` 只图传，不进行测量。测量与图传同时用时，必须在同一进程启动，先关闭旧的摄像头程序，不能同时启动两个程序抢设备。
- 本地模拟测试已通过；香橙派实机性能和网络尚未验证。图传会增加 CPU 和带宽负担，测量时核对实际采样帧率。
- 网页无登录认证，仅用于可信网络；不要把 8080 端口映射到公网。默认不加 `--host` 时仅本机可访问。

跨网络建议使用 VPN 将电脑和香橙派接入同一虚拟网络，随后用香橙派的 VPN IP 访问。更严格的方式是图传保持默认 `127.0.0.1` 监听，再通过 VPN 内的 SSH 隧道访问；不需要开放图传公网端口。在电脑终端运行（替换地址和实际 SSH 用户名）：

```bash
ssh -N -L 8080:127.0.0.1:8080 orangepi@香橙派VPN地址
```

香橙派同时运行 `python3 main.py --web --headless`，电脑打开 `http://127.0.0.1:8080`。SSH 隧道终端需保持开启；如果本地 8080 已占用，将 `-L` 的第一个端口改为 8081，浏览器也用 8081。普通局域网 IP 无法直接用于跨网络连接。
